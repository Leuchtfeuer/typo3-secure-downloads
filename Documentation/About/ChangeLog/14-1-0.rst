==========================
Version 14.1.0 - 2026/09/22
==========================

This release is a feature release.

Download
========

Download this version from the `TYPO3 extension repository <https://extensions.typo3.org/extension/secure_downloads/>`__ or from
`GitHub <https://github.com/Leuchtfeuer/typo3-secure-downloads/releases/tag/v14.1.0>`__.

Added
=====

* Add HTTP Range request support for file delivery, enabling partial content responses (e.g. for HTML5 video/audio seeking)

Changed
=======

* `BeforeReadDeliverEvent` is now dispatched once, right after the base header is set up, and listeners can override response headers (e.g. Content-Type, Content-Disposition) before response-type-specific defaults are applied
* Delivery via nginx `x-accel-redirect` is now only used when the request is actually running behind nginx; otherwise, the file is streamed through PHP automatically

Deprecated
==========

Removed
=======

* BREAKING: Remove the deprecated `outputFunction` property from `BeforeReadDeliverEvent`
