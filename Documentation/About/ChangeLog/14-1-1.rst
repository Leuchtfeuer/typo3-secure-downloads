===========================
Version 14.1.1 - 2026/10/13
===========================

This release is a bugfix release.

Download
========

Download this version from the `TYPO3 extension repository <https://extensions.typo3.org/extension/secure_downloads/>`__ or from
`GitHub <https://github.com/Leuchtfeuer/typo3-secure-downloads/releases/tag/v14.1.1>`__.

Added
=====

Changed
=======

* The extension metadata is now read from `composer.json`, which also carries the extension version. The TYPO3 extension repository no longer reads `ext_emconf.php`
* Describe the options `securedFiletypes` and `forcedownloadtype` as regular expressions matched against the file extension and name `.*` instead of `*` to match all files

Deprecated
==========

Removed
=======

* Remove `ext_emconf.php` (see TYPO3 Deprecation #108345)

Fixed
=====

* The configuration check no longer produces an invalid regular expression for the wildcard `*` in `securedFiletypes`
* The configuration check and the generated `.htaccess` example now cover files without extension when `.*` is used
* The backend module no longer disappears on `cache:warmup`, because it is now registered below the TYPO3 v14 parent module `content` instead of `web`
